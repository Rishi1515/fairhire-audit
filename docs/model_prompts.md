# Model prompts and parameters

Generated by `scripts/generate_report.py` from `src/fairhire/rank_llm.py` and `config/models.yaml`, so it always matches the code.

## LLM rubric scorer

- Model: `claude-haiku-4-5-20251001`
- Temperature: 1.0
- Repetitions per input: 5
- Maximum output tokens: 1200
- Strict evidence rule: False (when true, a non-zero level without a quote invalidates the reply)
- The overall score is computed from the per-competency levels with the rubric weights, never taken from the model.
- Parser statuses: ok, uncited_nonzero, invalid_json, schema_error, competency_mismatch, empty, not_run.
- Every call is cached in `results/llm_cache/` with the prompt, parameters, raw reply and token counts.

### System prompt

```text
You score resumes against a job rubric for a research benchmark on automated screening.
Rules:
1. Score only what is written in the resume. Do not credit skills the resume does not support.
2. Do not infer or consider gender, ethnicity, religion, age, nationality or any other personal attribute.
   The candidate's name, university name and career breaks must not change any score.
3. For every competency with a level above 0, quote one or more exact phrases from the resume as evidence.
4. Reply with a single JSON object and nothing else.
```

## Embedding model

- Model: `sentence-transformers/all-MiniLM-L6-v2` (ONNX), source `https://github.com/clems4ever/all-minilm-l6-v2-go` at commit `98aaab590a822d60ed359f7f8cb726e40daae4f4`
- SHA-256: `model.onnx` 994a58868f7abacacbf2192aa0aae8f56da8c4505dbde2740c861b24426ede6b, `tokenizer.json` da0e79933b9ed51798a3ae27893d3c5fa4a201126cef75586296df9b4d2c62a0
- Text is split at line breaks into pieces of at most 254 word pieces, embedded with mean pooling, averaged (weighted by piece length) and normalised. Score = 100 x cosine similarity, floored at 0.
- Section weights for the sectioned variant: {'header': 0.05, 'summary': 0.1, 'experience': 0.5, 'skills': 0.25, 'education': 0.1}
